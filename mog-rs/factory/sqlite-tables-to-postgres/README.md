# SQLite to Postgres

Convert a SQLite table definition to PostgreSQL DDL

Convert SQLite .schema output to PostgreSQL DDL: rewrites INTEGER PRIMARY KEY AUTOINCREMENT to a Postgres identity column, and maps SQLite storage classes (REAL->DOUBLE PRECISION, BLOB->BYTEA; TEXT/INTEGER pass through).

## Run

```
mog -m sqlite-tables-to-postgres <file>
```

Preview with `--dry-run` or `--diff`; write in place with `--in-place --backup .bak`.

## Example

Input:

```
CREATE TABLE customers (
  id INTEGER PRIMARY KEY AUTOINCREMENT,
  name TEXT NOT NULL,
  balance REAL,
  data BLOB,
  is_active INTEGER,
  created_at TEXT
);
```

Output:

```
CREATE TABLE customers (
  id BIGINT GENERATED BY DEFAULT AS IDENTITY PRIMARY KEY,
  name TEXT NOT NULL,
  balance DOUBLE PRECISION,
  data BYTEA,
  is_active INTEGER,
  created_at TEXT
);
```
