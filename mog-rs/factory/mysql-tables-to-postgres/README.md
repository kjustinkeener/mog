# MySQL SHOW CREATE TABLE to Postgres

Convert a MySQL table export to PostgreSQL DDL

Convert MySQL 'SHOW CREATE TABLE' output to PostgreSQL. Strips MySQL storage noise (ENGINE/CHARSET/COLLATE, backticks, DEFAULT NULL, ON UPDATE), then maps MySQL types to Postgres: tinyint(1)->BOOLEAN, datetime->TIMESTAMP, timestamp->TIMESTAMPTZ, json->JSONB, enum(...)->TEXT (value set flagged), and AUTO_INCREMENT->GENERATED BY DEFAULT AS IDENTITY. Minimal-diff. Validated by a live round-trip against a real PostgreSQL engine.

## Run

```
mog -m mysql-tables-to-postgres <file>
```

Preview with `--dry-run` or `--diff`; write in place with `--in-place --backup .bak`.

## Example

Input:

```
CREATE TABLE `products` (
  `id` bigint NOT NULL AUTO_INCREMENT,
  `sku` varchar(40) NOT NULL,
  `name` varchar(200) DEFAULT NULL,
  `description` text,
  `price` decimal(18,2) DEFAULT '0.00',
  `in_stock` tinyint(1) DEFAULT '1',
  `attrs` json DEFAULT NULL,
  `status` enum('active','discontinued') DEFAULT 'active',
  `created_at` datetime DEFAULT CURRENT_TIMESTAMP,
  `updated_at` timestamp NULL DEFAULT CURRENT_TIMESTAMP ON UPDATE CURRENT_TIMESTAMP,
  PRIMARY KEY (`id`)
) ENGINE=InnoDB DEFAULT CHARSET=utf8mb4 COLLATE=utf8mb4_0900_ai_ci
```

Output:

```
CREATE TABLE products (
  id bigint NOT NULL GENERATED BY DEFAULT AS IDENTITY,
  sku varchar(40) NOT NULL,
  name varchar(200),
  description text,
  price decimal(18,2) DEFAULT '0.00',
  in_stock BOOLEAN DEFAULT '1',
  attrs JSONB,
  status TEXT DEFAULT 'active', -- TODO(mog): MySQL ENUM mapped to TEXT; the allowed-value constraint was lost (use a CHECK or a Postgres ENUM type)
  created_at TIMESTAMP DEFAULT CURRENT_TIMESTAMP,
  updated_at TIMESTAMPTZ NULL DEFAULT CURRENT_TIMESTAMP, -- TODO(mog): MySQL ON UPDATE auto-refresh dropped; no portable equivalent (use a trigger/stream/task)
  PRIMARY KEY (id)
)
```

## Pipeline

- `run_mog`
- `replace_regex`: tinyint(1) is MySQL's boolean -> BOOLEAN.
- `replace_regex`: timestamp (instant) -> TIMESTAMPTZ. Runs before datetime so it does not re-match.
- `replace_regex`: datetime (wall-clock) -> TIMESTAMP.
- `replace_regex`: json -> JSONB (Postgres binary JSON).
- `flag_matching`: Flag ENUM (mapped to TEXT; value constraint lost).
- `replace_regex`: enum(...) -> TEXT.
- `replace`: MySQL AUTO_INCREMENT -> Postgres identity column.
