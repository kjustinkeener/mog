# Oracle GET_DDL to DuckDB

Convert an Oracle DBMS_METADATA.GET_DDL export to DuckDB DDL

Convert an Oracle DBMS_METADATA.GET_DDL export (storage suppressed) to DuckDB DDL. Flags and drops the inline IDENTITY spec and schema-qualified sequence NEXTVAL default (DuckDB has no inline IDENTITY; use a SEQUENCE + DEFAULT nextval), strips the GET_DDL boilerplate, and maps types: NUMBER(1,0)->SMALLINT, NUMBER(p,0)->BIGINT, NUMBER(p,s)->DECIMAL(p,s), bare NUMBER->DOUBLE, VARCHAR2->VARCHAR, CLOB/NCLOB->VARCHAR, RAW(n)->BLOB, TIMESTAMP(n) WITH TIME ZONE->TIMESTAMPTZ, TIMESTAMP(n)->TIMESTAMP, DATE->TIMESTAMP. Rewrites SYSDATE/SYSTIMESTAMP defaults to current_timestamp; VIRTUAL columns and CHECK/PRIMARY KEY/UNIQUE/NOT NULL constraints pass through. Execution-validated against a real DuckDB engine.

## Pipeline

- `flag_matching`: Flag Oracle inline IDENTITY (dropped below; DuckDB has no inline IDENTITY).
- `replace_regex`: Drop the inline IDENTITY spec (MINVALUE..NOSCALE); keep the trailing NOT NULL. DuckDB has no inline IDENTITY. Runs before the fragment while the clause is intact.
- `flag_matching`: Flag the Oracle sequence NEXTVAL default (dropped below; the referenced SEQUENCE does not exist in DuckDB).
- `replace_regex`: Drop the schema-qualified sequence NEXTVAL default. Runs before the fragment, which would otherwise strip the quoting and leave a bare NEXTVAL.
- `run_mog`: Strip Oracle GET_DDL boilerplate: schema qualifier, double-quote quoting, ENABLE, CONSTRAINT USING INDEX, TIMESTAMP (n) spacing.
- `replace_regex`: TIMESTAMP(n) WITH TIME ZONE -> TIMESTAMPTZ (before bare TIMESTAMP, else it re-matches).
- `replace_regex`: Bare TIMESTAMP WITH TIME ZONE -> TIMESTAMPTZ.
- `replace_regex`: TIMESTAMP(n) -> TIMESTAMP (DuckDB TIMESTAMP is microsecond-precision).
- `replace_regex`: NUMBER(1,0) -> SMALLINT (Oracle boolean-ish flag; DuckDB has no 1-byte int).
- `replace_regex`: NUMBER(p,0) -> BIGINT (integer columns).
- `replace_regex`: NUMBER(p,s) -> DECIMAL(p,s) (fixed-point; DuckDB DECIMAL max precision is 38).
- `replace_regex`: Bare NUMBER (unconstrained Oracle float) -> DOUBLE.
- `replace_regex`: VARCHAR2(n) -> VARCHAR(n) (DuckDB VARCHAR; the length is advisory).
- `replace_regex`: CLOB / NCLOB -> VARCHAR (DuckDB has one unbounded string type).
- `replace_regex`: RAW(n) -> BLOB (DuckDB BLOB is unsized). BLOB passes through unchanged.
- `replace_regex`: DATE -> TIMESTAMP (Oracle DATE carries a time component; DuckDB DATE is date-only). Runs after SYSDATE is safe: \b will not bite into SYSDATE.
- `replace_regex`: DEFAULT SYSDATE -> current_timestamp.
- `replace_regex`: DEFAULT SYSTIMESTAMP -> current_timestamp.
