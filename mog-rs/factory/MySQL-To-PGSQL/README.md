# MySQL (mysqldump) to PostgreSQL

Convert MySQL (mysqldump) DDL to PostgreSQL

Convert a mysqldump table-DDL export into PostgreSQL DDL. Strips dump scaffolding, rewrites backtick quoting, MySQL types, AUTO_INCREMENT, and ENUM/SET, and lifts inline KEY/UNIQUE/FULLTEXT indexes into standalone CREATE INDEX statements. Views, routines, triggers, and data are out of scope (stripped).

## Run

```
mog -m MySQL-To-PGSQL <file>
```

Preview with `--dry-run` or `--diff`; write in place with `--in-place --backup .bak`.

## Steps

- `run_mog`: Strip mysqldump scaffolding (comments, DELIMITER/LOCK/view blocks, SET/USE/DROP). Leaves CREATE TABLE blocks.
- `replace`: Remove backtick identifier quoting.
- `replace_regex`: Drop the table-options tail: ) ENGINE=... AUTO_INCREMENT=... CHARSET=... COLLATE... COMMENT... ; -> );
- `replace`: Drop MySQL charset introducers on literals (e.g. in generated-column expressions).
- `replace`: Drop ON UPDATE CURRENT_TIMESTAMP (no Postgres equivalent; needs a trigger, see docs).
- `replace`: AUTO_INCREMENT column -> GENERATED BY DEFAULT AS IDENTITY.
- `replace`: Drop 'unsigned' (Postgres has no unsigned integers; the range widens, see docs).
- `replace`: Type: tinyint(1) -> boolean.
- `replace_regex`: Type: bare tinyint -> smallint.
- `replace_regex`: Type: mediumtext/longtext/tinytext -> text.
- `replace_regex`: Type: blob family -> bytea.
- `replace_regex`: Type: double -> double precision.
- `replace_regex`: Type: datetime -> timestamp.
- `replace_regex`: Type: json -> jsonb.
- `replace_regex`: ENUM -> varchar with an inline CHECK (the column name is captured and reused).
- `replace_regex`: SET -> text (Postgres has no SET type; multi-value semantics are lost, see docs).
- `hoist_from_block`: Lift inline UNIQUE KEY definitions out to standalone CREATE UNIQUE INDEX after the table.
- `hoist_from_block`: Lift inline KEY / FULLTEXT KEY definitions out to standalone CREATE INDEX after the table (FULLTEXT becomes a plain index; use GIN/tsvector by hand, see docs).
- `flag_matching`: Flag STORED generated columns: Postgres requires an IMMUTABLE expression, and MySQL functions like concat_ws are only STABLE.
- `run_mog`: Canonical whitespace finalize via the shared fragment (tidy_chars picks the punctuation to de-space).
