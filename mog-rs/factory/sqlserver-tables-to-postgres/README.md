# SQL Server tables to PostgreSQL

Convert a real SSMS-scripted SQL Server table dump to PostgreSQL

Convert real SQL Server SSMS 'Generate Scripts' table output to PostgreSQL DDL. Strips the full SSMS scaffolding (object banners, SET options, CREATE/DROP DATABASE, ALTER DATABASE, the guarded DROP phase, filegroup placement, index storage options, CLUSTERED/NONCLUSTERED/ASC), rewrites GO batches to statements, maps every T-SQL type and datetime/uuid function, converts IDENTITY to a Postgres identity column, rewrites DEFAULT constraints to ALTER COLUMN ... SET DEFAULT, preserves sp_addextendedproperty 'MS_Description' as COMMENT ON TABLE/COLUMN, and flags computed/PERSISTED columns and bit->boolean 0/1 defaults (which need review in Postgres) with -- TODO(mog). Not a full SQL parser. Set schema_prefix (or --define schema_prefix=...) to control schema qualification.

## Run

```
mog -m sqlserver-tables-to-postgres <file>
```

Preview with `--dry-run` or `--diff`; write in place with `--in-place --backup .bak`.

## Pipeline

- `eol_lf`: Normalize to LF first so every later CRLF-sensitive regex is reliable. Output stays LF (standard for SQL scripts; psql reads it fine).
- `replace_regex`: sp_addextendedproperty 'MS_Description' on a COLUMN -> COMMENT ON COLUMN. Runs BEFORE the server-noise strip (which deletes extended properties) and before the TABLE rule so a column property is not mis-read as a table property. No trailing ; (the GO pass adds it).
- `replace_regex`: sp_addextendedproperty 'MS_Description' on a TABLE or VIEW -> COMMENT ON TABLE. Runs after the COLUMN rule.
- `run_mog`: Strip SQL Server server/session/DROP scaffolding first (object banners, SET options, CREATE/DROP DATABASE, ALTER DATABASE settings, the DROP phase, constraint re-enables, extended properties). Runs on the raw SSMS text while GO batches are intact. Reusable across object-kind converters.
- `replace`: Strip T-SQL square-bracket quoting: opening bracket.
- `replace`: Strip T-SQL square-bracket quoting: closing bracket.
- `replace`: Schema qualifier: rewrite the SQL Server 'dbo.' prefix. Default schema_prefix is empty, so objects become unqualified and resolve via search_path (public) -- the idiomatic Postgres result. Set schema_prefix to 'public.' or keep 'dbo.' as needed.
- `replace_regex`: USE <db> + its GO -> a documenting comment (Postgres has no USE; you connect to a database instead).
- `replace`: Function map: getdate() -> CURRENT_TIMESTAMP.
- `replace`: Function map: getutcdate() -> now() in UTC.
- `replace`: Function map: newid() -> gen_random_uuid() (Postgres 13+ builtin).
- `replace`: Function map: newsequentialid() -> gen_random_uuid() (no sequential-GUID equivalent in Postgres).
- `replace_regex`: Sequence default: NEXT VALUE FOR seq -> nextval('seq'). Runs before the DEFAULT-constraint rewrite so the captured value is already Postgres. NOTE: nextval quotes the name case-sensitively; see docs re: identifier case.
- `replace`: Function map: sysdatetimeoffset() -> now() (timestamptz). Must run before the 'datetime' type map, which would otherwise corrupt the name.
- `replace`: Function map: sysutcdatetime() -> now() in UTC.
- `replace`: Function map: sysdatetime() -> CURRENT_TIMESTAMP.
- `replace_regex`: Type map: datetimeoffset(n) -> timestamptz, dropping the precision (Postgres caps fractional seconds at 6; SSMS often scripts 7). Run before 'datetime'.
- `replace`: Type map: bare datetimeoffset -> timestamptz.
- `replace_regex`: Type map: datetime2(n) -> timestamp, dropping the precision (see datetimeoffset note). Run before 'datetime'.
- `replace`: Type map: bare datetime2 -> timestamp.
- `replace`: Type map: smalldatetime -> timestamp (run before datetime; it contains 'datetime').
- `replace`: Type map: datetime -> timestamp (whole word, so it never bites into an identifier or a sys*datetime* function that slipped through).
- `replace`: Type map: tinyint -> smallint (Postgres has no 1-byte integer).
- `replace`: Type map: uniqueidentifier -> uuid.
- `replace`: Type map: bit -> boolean (whole word). NOTE: 0/1 column DEFAULTs on these columns must be changed to false/true by hand; see docs.
- `replace`: Type map: nvarchar(max) -> text (run before varchar(max), which it contains).
- `replace`: Type map: varchar(max) -> text.
- `replace`: Type map: nvarchar -> varchar (Postgres varchar is already Unicode; no separate national type).
- `replace`: Type map: nchar -> char.
- `replace`: Type map: ntext -> text (bare 'text' is already valid Postgres).
- `replace`: Type map: smallmoney -> numeric(10,4) (run before money).
- `replace`: Type map: money -> numeric(19,4).
- `replace`: Type map: float -> double precision.
- `replace`: Type map: varbinary(max) -> bytea (run before varbinary / binary).
- `replace_regex`: Type map: varbinary(n) / bare varbinary -> bytea (Postgres bytea is unsized).
- `replace_regex`: Type map: binary(n) / bare binary -> bytea.
- `replace`: Type map: image -> bytea.
- `replace`: Identity: IDENTITY(1,1) -> GENERATED BY DEFAULT AS IDENTITY (the common case, kept clean).
- `replace_regex`: Identity with a non-(1,1) seed/step: IDENTITY(seed,step) -> GENERATED BY DEFAULT AS IDENTITY (START WITH seed INCREMENT BY step).
- `replace_regex`: SQL Server computed column 'col AS (expr) [PERSISTED]' has no portable Postgres form: generated columns require an explicit type the export does not carry. Drop the column and leave a TODO showing the Postgres shape to add by hand.
- `replace`: Drop ROWGUIDCOL column marker (no Postgres equivalent). squeeze_spaces (below) tidies the gap it leaves.
- `replace`: Drop SPARSE column marker (Postgres has no sparse columns).
- `replace`: Drop NOT FOR REPLICATION (identity/constraint modifier; no Postgres equivalent).
- `replace_regex`: Drop any index/constraint storage-option clause: WITH (PAD_INDEX = ...). One regex covers PK/UNIQUE constraints and standalone CREATE INDEX, which carry different option lists (FILLFACTOR, DATA_COMPRESSION, ...). A trailing ON PRIMARY is removed by a later step.
- `replace`: Drop filegroup placement 'ON PRIMARY TEXTIMAGE_ON PRIMARY'.
- `replace`: Drop remaining ' ON PRIMARY' filegroup placement.
- `replace`: Drop ' ASC' from key column lists (Postgres default; invalid inside these inline PK/UNIQUE column lists).
- `replace`: Drop ' NONCLUSTERED' (no Postgres equivalent).
- `replace`: Drop ' CLUSTERED' (Postgres has no clustered-index syntax on constraints).
- `replace_regex`: Constraint ALTER: '  WITH CHECK ADD  ' -> ' ADD ' (Postgres has no WITH CHECK ADD).
- `replace_regex`: Rewrite DEFAULT constraints to Postgres ALTER COLUMN ... SET DEFAULT (no trailing ; -- the GO pass adds it).
- `replace_regex`: SQL Server bit columns map to boolean, but their 0/1 DEFAULTs arrive as separate ALTER ... SET DEFAULT statements that cannot be correlated to the column type by regex (an int column can also default to 0/1). Flag each bare 0/1 default so the user changes boolean ones to true/false. Does not auto-convert (would corrupt genuine integer defaults).
- `replace_regex`: Turn each GO batch separator into a statement terminator, plus a blank line between statements.
- `replace`: Canonical Postgres spacing: 'FOREIGN KEY(' -> 'FOREIGN KEY ('.
- `replace`: Canonical Postgres spacing for covering indexes: 'INCLUDE(' -> 'INCLUDE ('.
- `run_mog`: Canonical whitespace finalize via the shared fragment (tidy_chars picks the punctuation to de-space).
