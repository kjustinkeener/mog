# Snowflake GET_DDL to Postgres

Convert a Snowflake GET_DDL table export to PostgreSQL DDL

Convert Snowflake GET_DDL('TABLE', ...) output to PostgreSQL DDL. Drops the trailing semicolon and the Snowflake-only cluster-by (flagged), table-comment, and column-comment renderings, rewrites autoincrement to a Postgres identity column, maps types (NUMBER(38,0)->BIGINT, NUMBER(p,s)->NUMERIC(p,s), VARIANT->JSONB, TIMESTAMP_NTZ->TIMESTAMP, TIMESTAMP_TZ/LTZ->TIMESTAMPTZ), and rewrites CREATE OR REPLACE TABLE to CREATE TABLE (Postgres has none). Not a semantic transpiler; leaves TODO(mog) markers where a construct needs manual review.

## Run

```
mog -m snowflake-tables-to-postgres <file>
```

Preview with `--dry-run` or `--diff`; write in place with `--in-place --backup .bak`.

## Example

Input:

```
create or replace TABLE CUSTOMERS (
	ID NUMBER(38,0) NOT NULL autoincrement start 1 increment 1,
	NAME VARCHAR(200),
	EMAIL VARCHAR(255) COMMENT 'primary contact email',
	BALANCE NUMBER(18,2),
	ATTRS VARIANT,
	CREATED_AT TIMESTAMP_NTZ(9),
	UPDATED_AT TIMESTAMP_TZ(9),
	REGION VARCHAR(50)
)COMMENT='customer master table'
cluster by (REGION);
```

Output:

```
CREATE TABLE CUSTOMERS (
	ID BIGINT NOT NULL GENERATED BY DEFAULT AS IDENTITY,
	NAME VARCHAR(200),
	EMAIL VARCHAR(255),
	BALANCE NUMERIC(18,2),
	ATTRS JSONB,
	CREATED_AT TIMESTAMP,
	UPDATED_AT TIMESTAMPTZ,
	REGION VARCHAR(50)
)
-- TODO(mog): dropped Snowflake CLUSTER BY (REGION) (no direct Postgres table-DDL equivalent)
```

## Pipeline

- `eol_lf`: Normalize to LF.
- `replace`: Drop statement terminators.
- `replace_regex`: Snowflake cluster by -> flag (Postgres CLUSTER is a maintenance command).
- `replace_regex`: Snowflake autoincrement -> Postgres identity.
- `replace_regex`: Drop inline column COMMENT 'x' (Postgres uses COMMENT ON).
- `replace_regex`: Drop the glued table )COMMENT='x'.
- `replace_regex`: VARIANT -> JSONB.
- `replace_regex`: NUMBER(38,0) -> BIGINT.
- `replace_regex`: NUMBER(p,s) -> NUMERIC(p,s).
- `replace_regex`: Bare NUMBER -> BIGINT.
- `replace_regex`: TIMESTAMP_NTZ(n) -> TIMESTAMP.
- `replace_regex`: TIMESTAMP_TZ / TIMESTAMP_LTZ -> TIMESTAMPTZ.
- `replace`: Postgres has no CREATE OR REPLACE TABLE.
